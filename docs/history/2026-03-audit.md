# Security & Bug Audit Pass (2026-03-09)

Fifteen audit items found and shipped in a single pass. All resolved.

- [x] **1. SQLite WAL mode** — `PRAGMA journal_mode=WAL` applied at startup.
- [x] **2. SSRF protection** — blocks localhost, private IPs (10/172.16/192.168), link-local, `.local`/`.internal` hostnames.
- [x] **3. HTTP response size limit** — 10 MB cap via `LimitedStream` wrapper + `ContentLength` pre-check.
- [x] **4. `.Max()` empty collection** — guarded with `Count != 0` check (matches `UpdateProduct` pattern).
- [x] **5. Security headers** — `SecurityHeadersMiddleware`: X-Content-Type-Options, X-Frame-Options, CSP, Referrer-Policy.
- [x] **6. `handleAddUrl` error handling** — wrapped in try/catch, shows `actionError` instead of closing modal.
- [x] **7. Dashboard error display** — `loadError` state with retry button shown when API fails.
- [x] **8. CommandPalette race condition** — sequence counter discards stale search results.
- [x] **9. Duplicate URL race condition** — `DbUpdateException` catch around `SaveChangesAsync` for graceful conflict.
- [x] **10. SMTP timeout** — `SmtpClient.Timeout = 15_000` (15 seconds).
- [x] **11. Email enumeration** — registration returns generic 422 "Unable to create account" (no email leak).
- [x] **12. Timer memory leaks** — `onDestroy` cleanup in `ProductCard` and `ProductTable`.
- [x] **13. `handleRetryScrape` clears `actionError`** — clears error before retry, shows toast on success.
- [x] **14. `DataRetentionService` race** — `Interlocked.CompareExchange` prevents concurrent cleanup.
- [x] **15. Error display on all pages** — Dashboard, comparisons, comparison detail, stores all show error state with retry.

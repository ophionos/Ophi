# UI/UX Innovation Pass (2026-03-17)

**Goal:** Give Ophi a distinctive visual identity beyond "Tailwind dashboard template." Make prices feel alive, data feel visceral, and the app instantly recognizable as a price tracker.

## Phase A — Low Effort, High Return

### A1. Sparklines in Product Cards
- [x] Tiny sparkline SVG (64×20px, no axes) in each product card's price row
- [x] Polyline from 14-day price history; color follows trend (green=declining, red=rising, gray=flat)
- [x] Pure inline SVG — no Chart.js dependency
- [x] Backend: `?includeSparkline=true` opt-in query param, batch PricePoints query (no N+1)
- [x] Frontend: `Sparkline.svelte` component, dashboard passes flag when `viewMode === 'grid'`
- **New files:** `Sparkline.svelte`, `Sparkline.test.ts`
- **Modified:** `GetProducts.cs` (Query, ProductDto, Handler), `client.ts`, `ProductCard.svelte`, `dashboard/+page.svelte`

### A2. Brand Color Shift (Teal-Indigo Gradient)
- [x] Replaced flat `blue-600` with semantic `brand` color system (teal-600 `#0d9488` primary)
- [x] 156 occurrences across 45 files systematically replaced
- [x] Tailwind `extend.colors.brand` palette: DEFAULT, hover, light, subtle, dark, muted, secondary
- [x] CSS `@utility bg-brand-gradient` for gradient accent
- [x] Dark mode fully supported via `brand-muted` (`#2dd4bf` / teal-400)
- **Modified:** `tailwind.config.js`, `app.css`, all 45 component/page files

### A3. Price Position Bar
- [x] Thin 4px horizontal bar at top of each product card
- [x] Gradient from green (historical min) to red (historical max), marker dot at current position
- [x] Color logic: green in lower third, amber in middle, red in upper third
- [x] Reuses `priceMin`/`priceMax` from A1's batch query — no additional backend cost
- **New files:** `PricePositionBar.svelte`, `PricePositionBar.test.ts`
- **Modified:** `ProductCard.svelte`

### A4. Animated Number Transitions
- [x] `createAnimatedPrice()` utility with requestAnimationFrame + cubic-out easing (600ms)
- [x] Numbers count to value on load/change instead of snapping
- [x] Applied to: product card prices, product detail stat cards (Lowest, Highest, Average, Current)
- **New files:** `animatedPrice.svelte.ts`, `animatedPrice.test.ts`
- **Modified:** `ProductCard.svelte`, `products/[id]/+page.svelte`

## Phase B — Medium Effort, High Differentiator

### B1. Deal Score Indicator
- [x] Computed 0–100 score per product (distance from low 40%, trend direction 30%, alert proximity 30%)
- [x] Small 24px radial progress ring on product card (red <30, amber 30–60, green >60)
- [x] Backend: `ComputeDealScore` static helper in `GetProducts`, wired into both `GetProducts` (gated on `includeSparkline`) and `GetProduct` (always computed)
- [x] Frontend: `DealScore.svelte` SVG component with clamped score, color-coded stroke
- [x] Integrated into `ProductCard.svelte` (image overlay) and product detail page (next to title)
- **New files:** `DealScore.svelte`, `DealScore.test.ts`
- **Modified:** `GetProducts.cs`, `GetProduct.cs`, `ProductCard.svelte`, `products/[id]/+page.svelte`, `client.ts`

### B2. Price Story Labels
- [x] Contextual insight labels with priority system: "Just dropped!", "Lowest in 14 days", "Near all-time low", "X% below average", "Steady for X days", "Trending down", "Price rising"
- [x] Pure frontend utility `getPriceStory()` — no backend changes needed
- [x] Labels displayed as colored pills below sparkline in product cards and below title in product detail
- [x] Four variants: positive (green), negative (red), neutral (gray), highlight (brand teal)
- **New files:** `priceStory.ts`, `priceStory.test.ts`
- **Modified:** `ProductCard.svelte`, `products/[id]/+page.svelte`

### B3. Landing Page Redesign
- [x] Animated price ticker tape (CSS `@keyframes ticker`, 25s infinite loop with duplicated items)
- [x] 5-step "How it works" visualization: Paste URL → Auto-extract → Track drops → Get notified → Save money
- [x] Bold gradient tagline: "Never pay **full price** again" with staggered fade-in-up animations
- [x] 4 feature cards (Track Any Product, Smart Alerts, Deal Score, Self-Hosted) with hover effects
- [x] Stats bar (100+ stores, 24/7 monitoring, 0 data shared) + footer CTA
- [x] Brand gradient CTAs with shadow and hover elevation effects
- **Modified:** `+page.svelte`, `app.css` (ticker + fade-in-up keyframes)

## Phase C — Medium-High Effort, Unique Features

### C1. Activity Feed View
- [x] Third dashboard view mode (grid | list | feed) with Activity icon toggle
- [x] Chronological stream of price events derived from existing product data (no new backend endpoint)
- [x] Each event: trend icon (green/red), product name link, DealScore badge, price change amount/percent, alert count, relative time
- [x] Events sorted by `lastChecked` descending, empty state for no activity
- **New files:** `ActivityFeed.svelte`, `ActivityFeed.test.ts`
- **Modified:** `dashboard/+page.svelte` (view mode toggle, includeSparkline for feed mode)

### C2. Comparison Winner Spotlight
- [x] Visually elevated winning product: larger image (w-20 h-20), green ring/background, bold green price, Trophy icon badge
- [x] Price gap display: "You save {currency} {amount} vs next cheapest" computed from sorted product prices
- [x] Upgraded banner from plain "Best Price" to gradient "Winner" spotlight with larger typography
- **Modified:** `comparisons/[id]/+page.svelte`, `comparison-detail.test.ts`

### C3. Scanning Animation (Product Add)
- [x] Staged animation replacing pending spinner: "Connecting..." → "Reading page..." → "Extracting price..." (1.5s intervals)
- [x] Simulated page outline with fake content lines + animated scan line sweep (CSS `@keyframes scan-sweep`)
- [x] Progress bar tracking stage completion
- **New files:** `ScanAnimation.svelte`, `ScanAnimation.test.ts`
- **Modified:** `ProductCard.svelte` (pending state), `app.css` (scan-sweep keyframes)

## Implementation Order

```
A1 (Sparklines) → A2 (Brand colors) → A3 (Price bar) → A4 (Animated numbers)
    → B1 (Deal score) → B2 (Story labels) → B3 (Landing page)
        → C1 (Activity feed) → C2 (Comparison spotlight) → C3 (Scanning animation)
```
